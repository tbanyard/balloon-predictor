# BalloonPredictor v1.5.1

The server edition still starts with `bash start.sh --port 8004` (or your
chosen port). See [v1.5 installation and connection instructions](V1.5.md)
for Windows, macOS, Android and Debian. Reuse your existing data directory
and server configuration.

- The Trajectory toolbar stays on one row. Click the down arrow for any
  controls that do not fit. Track stages and endpoint switches stay on
  ascent and target for **Stop at target altitude**. Sensitivity is independent.
- **Sensitivity region** encloses the nominal endpoint and the successful
  members with a fixed 1 km margin. Zoom changes the view, not the region.
- Elapsed-time charts use round seconds or minute intervals.
- CDS weather jobs show accepted/queued, preparing, and download stages
  when the service reports them, then local conversion and saving.

## Missing landing terrain

The physical DEM is sampled along the descent to find the first terrain
intersection. It is not needed for the ascent unless selected for launch
ground. The error now names the missing sample and offers **Download required
descent DEM and retry** when there is a GLO-30 tile to try. If another part of
the descent needs a separate tile, the next run offers that tile. The app
never substitutes sea level for an unknown pixel. If public coverage is
missing or a tile is nodata, add a covering GeoTIFF, use model terrain, or
enter a known fixed landing elevation.

## Android without a connection

1. While online, calculate a flight with a **downloaded regional IFS, GFS, or
   pressure-level ERA5/ERA5T dataset** on the server.
2. In **Flight Details**, choose **Save offline forecast for Android** and keep
   the `.bpforecast` file on the phone (for example, in Downloads).
3. In the Android app choose **Server → Run locally · offline forecast**,
   open the pack, and calculate on the phone. The pack includes the
   selected flight's setup, grid cells, vertical levels, and adjacent
   forecast times where available. Check its UTC coverage before launch.

The offline calculator handles one ascent or full flight, forecast terrain
or a fixed landing height, a coastline map, and CSV/GeoJSON. New forecasts,
native ERA5/WRF, physical DEM, sensitivity runs, flight plans and NetCDF
exports still use the server. Offline flights must stay inside the saved
forecast in space, height and time. Save a fresh pack before going out.

The Android APK is still a direct download. Use the same Android signing
key as before to install this version as an update. If previous APKs were
signed with temporary keys, a one-time uninstall may be needed.
