    Use your WRF output or existing weather files
    Native WRF output is indexed directly from /data1/tim/SkySightWRF. Keep each run in its own folder and use standard wrfout_d01_… / wrfout_d02_… files. Click Rescan local data, then select the run/domain. Only actual timestamps are used; unavailable dates and coverage gaps report an explanation.
    Change wrf_root or era5_root in config.yml for another location. Large WRF files can stay where they are; no upload or full-volume conversion is needed.
    The existing cropped import workflow is also available:
    python -m balloon_predictor import-wrf --name my-wrf \
  --files "/data1/tim/SkySightWRF/wrfout_d02_*" \
  --area 60 -12 48 5
    For existing pressure-level ERA5/IFS GRIB or NetCDF, use import-era5 / import-ifs. See docs/WRF.md for required WRF variables, humidity, multiple runs and limitations.
